03 Operating method

The loop

Observe.
Structure.
Improve.

  1. 01

    Find the real constraint

    Start with evidence, not a fashionable tool or a predetermined answer.

  2. 02

    Build the smallest useful loop

    Connect the minimum inputs, actions, and checks needed to produce a measurable result.

  3. 03

    Measure what changed

    Use the result to decide what deserves refinement, automation, or removal.

  4. 04

    Document what holds

    Turn durable lessons into systems, writing, and shared practice.
