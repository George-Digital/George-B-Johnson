# AI System Evaluation, Reliability & Governance

## Course name

AI System Evaluation, Reliability & Governance

## Course description

Make one AI-assisted workflow measurable, reviewable, and dependable enough for its intended use. Build representative test cases, score outputs, set thresholds and escalation paths, define permissions and human review, and finish with a reliability pack that records evaluation, incidents, changes, and operating ownership.

**Unicode character count:** 324

## Prerequisite and outcome

**Prerequisite:** A working or prototype AI-assisted workflow with a defined user, input, output, and a person who understands the work well enough to review it.

**Outcome:** A member completes a Reliability Pack with a scoped evaluation set, scoring rubric, thresholds, escalation and recovery paths, permissions and data boundaries, assigned decision ownership, incident and change records, and an evaluation cadence. The pack supports a bounded operating decision; it does not certify a system as safe for every use or replace qualified judgment.

## Resources (7 member resources)

- **Evaluation Set Template** — scope, case inventory, expected behavior, and evaluation evidence.
- **Output Scoring Rubric Template** — observable scoring criteria, calibration, and acceptance gates.
- **Evaluation Case Generator Prompt** — a bounded way to draft candidate test cases for human review.
- **Failure and Escalation Log** — failures, stop conditions, owners, actions, and closure evidence.
- **Governance and Permissions Checklist** — data, access, decision, review, and change boundaries.
- **Incident and Change Record** — connected incident, correction, approval, retest, and closure evidence.
- **Reliability Review Template** — the final operating review and Reliability Pack handoff.

## Completion standard

A completing member has one clearly scoped system and intended-use boundary; named stakes, reviewers, and decision owners; a representative evaluation set with expected behavior and edge cases; a consistent scoring rubric and quality thresholds; documented stop, escalation, fallback, recovery, permissions, and data-handling paths; a completed Incident and Change Record linked to the failure log; a recurring evaluation cadence; and a current Reliability Pack. For high-impact decisions involving health, law, employment, housing, education access, finance, safety, benefits, discipline, or essential services, the pack must keep AI output advisory and route the final determination to an appropriately qualified human.
