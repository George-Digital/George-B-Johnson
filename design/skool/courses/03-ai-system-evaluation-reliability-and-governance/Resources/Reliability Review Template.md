# Reliability Review Template

**Use this template to assemble the current Reliability Pack, review the evidence behind a bounded workflow, and make a documented keep, revise, restrict, or pause decision.**

This review supports accountable operation. It does not certify a system as safe, compliant, fair, or suitable for every use. AI output remains advisory where a qualified human must make the final decision.
