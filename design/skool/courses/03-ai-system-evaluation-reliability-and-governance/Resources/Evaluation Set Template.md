# Evaluation Set Template

**Use this template to define the intended use, select safe cases, state expected behavior before a run, and preserve evidence without overstating what a small evaluation proves.**

Use authorized, minimized, anonymized, or clearly labeled synthetic material. Keep private records in approved locations and place only safe descriptions or secure references in this template. A qualified human retains final authority over high-impact decisions involving health, law, employment, finance, housing, benefits, education access, safety, discipline, or essential services.
