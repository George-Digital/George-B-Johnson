# Client Knowledge Portal course art

## Skool course cover

- **Upload file:** `client-knowledge-portal-cover-1280x720.png`
- **Dimensions:** 1280 × 720 pixels
- **Aspect ratio:** 16:9
- **Format:** PNG

This is the course-level Classroom cover. Upload it through the live course image field; do not create a Course Art folder or page in the member curriculum.

The cover stays within the established Builders Lab visual system while changing the course path to **Upload → Record → Review → Approve**. Its promise matches the course: private files, tracked status, and human approval before agent use.
