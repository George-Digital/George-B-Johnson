# Context & Knowledge Systems for AI Workflows

## Course name

Context & Knowledge Systems for AI Workflows

## Course description

Build a maintainable source of truth for one AI-assisted workflow. Inventory approved sources, separate facts from rules and examples, define ownership and access boundaries, test grounding and missing-context behavior, and hand off a documented context pack for human-reviewed use.

**Unicode character count: 282**

## Prerequisite and outcome

**Prerequisite:** A completed Sprint system or an equivalent workflow brief with a defined user, input, output, and human-review point.

**Outcome:** Create a maintainable, traceable source of truth for an AI-assisted system, including its approved sources, structure, ownership, update rules, access boundaries, retrieval tests, and handoff record.

## Completion standard

A member who completes this course should finish with a Context Pack containing:

- a confirmed knowledge-system use case, scope, user, and human-review boundary
- an inventory and map of current sources, their authority, owners, access limits, and review dates
- a build log that records source decisions, tests, changes, and unresolved questions
- a clear separation of approved facts, operating rules, examples, and decisions reserved for people
- a context-intake process that preserves provenance and rejects or routes unsuitable material
- a usable knowledge structure with source references and retrieval cues
- named ownership, update cadence, expiration rules, access permissions, and privacy limits
- a documented response for missing, stale, and conflicting context
- a first context pack tested on grounded, missing-context, and conflict cases
- an honest handoff with limitations, access boundaries, review responsibilities, and a next review date

Completion means the system has a reviewable first version, not that the knowledge is complete, permanently current, or safe to use without human judgment.
