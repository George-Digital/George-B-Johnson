# Self-hosted typefaces

The site self-hosts Latin webfont subsets to avoid third-party font requests.

- IBM Plex Mono — Google Fonts source, SIL Open Font License 1.1
- Instrument Serif — Google Fonts source, SIL Open Font License 1.1
- Manrope — Google Fonts source, SIL Open Font License 1.1

License texts are retained in `licenses/`.
